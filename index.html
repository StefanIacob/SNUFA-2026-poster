Heterogeneous spike coding networks

Stefan Iacob, Sander Keemink, Fleur Zeldenrust · Donders Centre for Neuroscience, Radboud University · SNUFA 2026

Introduction

  • Biological brains exhibit a large degree of timescale heterogeneity. Similarly, to obtain reliable neuromorphic systems, heterogeneity in neuronal parameters is required.
    • Spike coding networks (SCNs) [1] are biologically plausible models of spiking neural circuits, that encode information with a minimal number of spikes, while being robust to noise and neuron loss [2].
    • SCNs rely on tracking a global encoding error in a distributed way, by tracking components of the error in each neuron's membrane voltage.
    • While voltages track error, spikes indicate exceeding an error tolerance in a particular direction. All thresholds together form a bounding box around the target [3].
    • To generate a continuous output, a synaptic filter is applied to the spikes to generate an instantaneous rate signal, which is then scaled with a decoder.
    • Problem: to correctly track the error using membrane voltages, without an explicit global error signal, SCNs rely on a membrane voltage decay that is identical across neurons and between membranes and synapses. Deviating from this assumption of homogeneous timescales causes a drifting and incoherent error representation.
    • We present a heterogeneous SCN, that compensates drifting error representations using an additional set of slow synaptic weights.
    • In addition to deriving these optimal synaptic slow weights, we show that they can be learned and maintained using a local learning rule.

Heterogeneity in Spike Coding Networks

  • Timescale heterogeneity in SCNs can be added by varying timescales between neurons, and by varying the timescales between membranes and decoders (Figure 2).
  • Mismatch between membrane decay and synapse decay causes a drifting but coherent error representation (Figure 1, model 2).
  • Fully heterogeneous timescales cause an incoherent representation (Figure 1, model 3).
  • Compensating the resulting error representation drift requires an additional set of slow weights (Figure 3). These slow weights transmit the filtered spikes rather than the spikes themselves. This gives us the following differential equation:
dVdt=−ΛvV+𝐅d𝐱dt+Λv𝐅𝐱−Ωf𝐬 +Ωs𝐫slow weights

where Λv is the diagonal matrix with entries λvi, the membrane decay rate of neuron i.

  • The compensatory slow weights are
Ωs(i,k)= DiTDk((λdk−λdi)−(λdi−λvi))
  • The resulting heterogeneous network correctly tracks the error. These heterogeneous SCNs perform similarly to a homogeneous SCNs (Figure 1, model 4).

Learning the slow weights

  • To learn the slow weights locally, each neuron should make its voltage track its projected error. The voltage Vi should therefore have the same value as the error EDi, and it should move at the same speed. We define one loss for each:
Li(0)=(Vi−EDi)2same value Li(1)=(dVidt−dEDidt)2same speed
  • The slow weights follow the gradient of the sum of the two losses:
ΔΩsij=−η∂∂Ωsij(Li(0)+Li(1))
∂Li(0)∂Ωsij=2rjλvi−λdj(Vi−EDi) ∂Li(1)∂Ωsij=−2λdjrjλvi−λdj(dVidt−dEDidt)

where rj is the filtered spike train of presynaptic neuron j.

  • With the learned slow weights, the heterogeneous network tracks the error again (Figure 1, model 5).
  • The slow weights converge to the optimum. Networks with different decoders and timescales (n = 6), each starting from non-optimal slow weights, reach a similarity of 99.6–99.8% with the optimal slow weights (Figure 4).

Conclusion

  • We derive a set of slow weights that compensate faulty (i.e., drifting or incoherent) error tracking in heterogeneous SCN membranes.
  • We show that these slow weights can be learned using a homeostatic local learning rule. This finds the optimal slow weights, and maintains them in the event of changing timescales.
  • Building in robustness to heterogeneity in SCNs improves their use as a model of spiking neural circuits, as well as their potential for neuromorphic implementations. Although tolerance for heterogeneity is shown here, it remains an open question whether heterogeneous timeconstants may be beneficial for SCNs.
